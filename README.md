# Polarity Integration Utils

This library is intended for use in development of Polarity Integrations.



> NOTE: Some methods will just throw `NotImplementedError`.  These methods are ones that have their functionality implemented in multiple integrations, and seem likely to come up in future integrations, but has not been implemented yet in this library due to time constraints.  The plan is to implement these methods as they come up during integration development.

## Contribution Instructions

> NOTE: Don't forget to add your implementations to the `./test/index.test.js` to ensure your implementation is accessible from the main index.js
